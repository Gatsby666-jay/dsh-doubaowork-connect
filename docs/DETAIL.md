# DSH Connect 豆包工作

把本机登录的 **豆包工作** 接进 DeepSeek Harness 的模型选择器：模型清单按上游目录刷新，积分倍率由上游给出，支持逐模型图片输入开关、多账号与账号池自动换号，并在设置页与输入框里提供只读的积分读数。

## 它做什么

- **模型选择器里出现豆包工作的模型。** 清单按上游目录刷新；拿不到时依次退到磁盘缓存、内置快照，所以刷新失败不会让选择器变空。
- **倍率完全由上游给出。** 豆包把倍率放在模型条目的标签文案里，插件只解析这段文案，并把上游打印的那一段原样做成徽章（`0.80x` 不会变成 `0.8x`）。上游没给就显示 `—`，从不补一个数字。
- **逐模型的图片输入开关。** 默认全部关闭；打开后该模型才在选择器里声明图片能力，也才真的接受图片。
- **多账号与账号池。** 池成员显式勾选，默认一个都不含。
- **只读的积分读数。** 设置页有额度与签到状态，输入框里有一颗胶囊式的积分读数。

## 账号从哪来

两条路，都不需要装额外的东西：

1. **从本机豆包客户端读取**（推荐）。点一下就把客户端里的登录态读出来，包括 `sessionid`、CSRF token 和设备标识。客户端开着也能读——它把 Cookie 库锁住了，插件会先复制一份再解析。
2. **粘贴 Cookie。** 在已登录的 `www.doubao.com` 页面里复制 Cookie 请求头，粘进来保存。至少要有 `sessionid`。

读到的账号存进插件自己的状态文件（`$DSH_HOME/.doubaowork.cn.json`，权限 600），此后与客户端解耦：客户端退出登录、切号、甚至卸载，已导入的账号照常工作。只有服务端让 Cookie 过期了才需要重新登录一次。

某个配置读不出来时，页面会把原因逐条列出来——占用、没有会话、app-bound 加密各不相同，处理方式也不同。

## 账号池怎么工作

池成员是**显式勾选**的，默认一个都不含——开关打开但没人被勾选时，仍然用当前账号，免得误点一下就把所有请求弄失败。

- **池关着**：当前选中的账号服务所有请求。
- **池开着**：勾选的账号按顺序轮流服务。某个账号登录失效、被要求人工验证、或者被限流时，**这一次请求**自动换下一个账号，失败的账号进冷却（失效 12 小时、验证 30 分钟、限流 3 分钟），不会在紧循环里反复撞。
- **网络错误和上游格式错误不换号。** 那跟账号无关，换一个账号只会再失败一次，所以直接把错误交给用户看。

设置页的「清除冷却并重试」会把所有冷却清掉并立刻重读积分与签到，方便你处理完验证 / 重新登录后马上看到是否恢复。

## 积分与签到：为什么是只读

额度读的是 `/alice/commerce/sale/subscription/quota/summary/`，签到状态读的是活动详情里的 `daily_checkin` 节点。两者都只读。

**插件不会代你签到**，原因不是保守：网页会话签不了，而且试图代签失败会把当天的额度直接作废——实测拿到 `710010702` 之后，客户端里再点签到会提示「当前暂不符合领取条件」，当天就没法补了。所以这里只显示「今日已签 / 今日未签 · 连续 N 天」，要签到请去豆包客户端点。

上游没报的金额显示 `—`，不显示 `0`：把「没报」画成「用完」会让人以为额度见底。

## 设置页的两个 tab

- **账号**：导入 / 粘贴账号、切换当前账号、重命名、移除（有确认）、账号池开关与成员勾选、积分与签到读数。
- **模型**：目录来源与刷新时间、每个模型的倍率徽章、上下文与推理档位、两个开关（显示 / 图片输入）。

输入框右侧的胶囊式读数点开后显示账号、剩余积分、对应额度窗口、签到状态与读数更新时间。胶囊每 60 秒读一次本地状态，额度超过 90 秒才回上游刷新。

## 已知边界

- **豆包没有对外开放的 API**，这里用的是客户端自己走的内部协议，会随客户端版本变化而失效。验证于 2026-11。
- **风控**：一旦豆包要求人工验证（`710022004` 这一类），去 `https://www.doubao.com/chat/` 手动发一句话完成验证；验证没过之前反复重试只会让限制更久。
- **app-bound Cookie 解不开**：如果客户端的 Cookie 用 `v20` 前缀（新版 Chromium 的 app-bound 加密），插件会明确报错，此时请在客户端里退出再登录一次（会换回 `v10`），或者改用粘贴 Cookie。
- **签到不能代签**，见上。
- 图片输入需要先把图片传到豆包存储再随请求发送；上传后按账号隔离，不跨账号共享。
- 目录刷新后会丢弃上游已下架的模型：一个已停用的模型继续挂着旧倍率，等于在报一个并不存在的价。

## 隐私

- 登录态只存本机 `$DSH_HOME/.doubaowork.cn.json`（权限 600），不上传任何地方。
- 插件不收集遥测，不访问豆包之外的域名（图片上传会用到豆包返回的 ImageX / 存储域名，且只带短期上传凭证，不带 Cookie）。
- 设置页的 HTTP 接口要求 `Host` 为本机回环地址，并在带 `Origin` 时要求同为回环。这挡住的是「别处网页驱动这些接口」——浏览器一定发送自己的 `Origin`，网页也无法伪造 `Host`。同机上的非浏览器进程仍可调用：插件跑在你自己的会话里，没有更强的身份可校验。
